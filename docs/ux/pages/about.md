# About page UX direction

- **Observed:** About connects Suyog's experience, current focus, principles,
  and selected proof without reproducing a full résumé.
- **Observed:** The page uses an editorial narrative, timeline-like evidence,
  and restrained calls to continue into work or contact.
- **Derived principle:** Personal credibility should come from specificity and
  coherent experience, not self-promotional visual treatment.

## Invariants

1. Current focus and the site's purpose remain clear early.
2. Experience is selective and relevant to intelligent software systems.
3. Beliefs are paired with evidence or practical work where possible.
4. The page feels personal but retains the site's composed editorial tone.
