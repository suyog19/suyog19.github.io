# Writing page UX direction

- **Observed:** Writing is an editorial catalogue with three complementary
  entry modes: latest work, reader-intent paths, and topic clusters.
- **Observed:** Publication date, topic, source, and internal/external location
  are visible metadata. Thumbnails support the latest stream but do not replace
  titles or summaries.
- **Observed:** The main series is separated as an ordered practical guide.
- **Derived principle:** Help both returning readers seeking recency and new
  readers seeking orientation; neither view should erase the other.
- **Derived principle:** Dense catalogues need strong labels, rules, and grouping
  more than decorative card treatments.

## Invariants

1. Latest content remains easy to identify.
2. Reader paths explain who they help and where to begin.
3. Topic clusters remain descriptive, not merely tag clouds.
4. External publication links are clearly distinguished.
5. Mobile retains scannable metadata and avoids horizontal overflow.
